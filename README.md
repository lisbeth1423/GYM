# Lis en movimiento

Aplicación móvil para registrar una rutina de gimnasio de tres días durante ocho semanas.

## Funciones

- Rutinas de jueves, viernes y sábado.
- Registro de peso, repeticiones y ejercicios completados.
- Fotografías y recomendaciones de técnica.
- Histórico del entrenamiento anterior.
- Respaldo local cuando no hay conexión.
- Sincronización con Google Sheets mediante Apps Script.

La aplicación se publica con GitHub Pages desde `index.html`.

Las fotografías de ejercicios proceden de [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), distribuido bajo Unlicense/dominio público.
